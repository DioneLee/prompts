잿빛 탑의 밤

AI와 함께 만든 포인트 앤 클릭 미스터리 게임,
그 제작 과정을 다섯 단계 프롬프트로 정리했어요.

1 · 게임 본체2 · 실사 배경3 · 실시간 조명4 · 살아있는 배경5 · 공개하기고급 · 한 번에

특정 도구를 쓸 필요는 없어요. 지금 쓰고 있는 AI 채팅, 이미지, 영상 도구로 시작하면 되고, 결과물 품질은 도구마다 조금씩 달라요.
한 번에 완성된 게 아니라 여러 번 대화하며 다듬은 과정을 순서대로 정리한 거예요. 단계마다 결과를 직접 플레이해 보고 고칠 점을 이어서 요청하면 훨씬 좋아져요.

STEP 1

게임 본체 만들기

AI 채팅 · 코딩 도구

세계관, 장면, 시스템을 구체적으로 적을수록 결과가 좋아요. 잿빛 탑 원본을 그대로 써도 되고, 아래 빈칸 템플릿으로 나만의 게임을 만들어도 돼요.

PROMPT · 잿빛 탑 원본
'검은방' 스타일의 포인트 앤 클릭 탈출+추리 게임을 HTML 파일 하나로 만들어줘.

[세계관]
1년 전 불타버린 판타지 마탑 '잿빛 탑'. 기사 리안이 탑 꼭대기 감방에서 깨어난다.
초대장에는 단 한 줄, "너의 죄를 기억하라."

[구성]
- 5개 챕터, 장면 6개: 감방 → 복도 → 예배당 → 얼어붙은 서재 → 엘라의 방 → 대전당
- 등장인물 5명(주인공 포함), 모두 1년 전 화재와 관련된 비밀이 하나씩 있음
- 중반에 살인 사건 1건, 마지막은 범인을 지목하는 심판

[시스템]
- 화면 사물 클릭 = 조사, 소지품 선택 후 대상 클릭 = 사용, 소지품 두 개 차례로 클릭 = 조합
- 키워드 파일(단서 수첩), 다이얼 자물쇠 퍼즐, 힌트 버튼, '살펴보기'(클릭 가능한 곳 잠깐 표시)
- 타이틀 화면, 자동 저장/이어하기, 엔딩 4개(배드 2, 노멀 1, 트루 1)와 엔딩 기록
- 대화창에 인물 초상화와 타자기 효과, 효과음과 배경음은 Web Audio로 직접 합성

[기술]
- 외부 라이브러리 없이 HTML/CSS/JS 한 파일
- 장면은 1024x1024 SVG, 그 위에 투명한 클릭 영역(hotspot)
- 배경 그림은 나중에 이미지로 교체할 수 있게 장면별 이미지와 클릭 좌표를 한곳에 모아서 관리
- 완성 후 처음부터 모든 엔딩까지 막히는 곳이 없는지 직접 점검해줘

{ } 안을 내 이야기로 바꿔 넣으세요.

PROMPT · 빈칸 템플릿
{장르} 스타일의 포인트 앤 클릭 탈출+추리 게임을 HTML 파일 하나로 만들어줘.

[세계관]
{배경 2~3줄. 예: 1년 전 불타버린 판타지 마탑. 주인공이 탑 꼭대기 감방에서 깨어난다.}
{시작 계기 한 줄. 예: 초대장에는 단 한 줄, "너의 죄를 기억하라."}

- {챕터 수}개 챕터, 장면 {장면 수}개: {장면1} → {장면2} → {장면3} → ...
- 등장인물 {인물 수}명(주인공 포함), 각자 {공통 사건}과 관련된 비밀이 하나씩 있음
- 중반에 {핵심 사건} 1건, 마지막은 {결말 방식. 예: 범인을 지목하는 심판}

- 타이틀 화면, 자동 저장/이어하기, 엔딩 {엔딩 수}개와 엔딩 기록

STEP 2

실사풍 장면 이미지

이미지 생성 AI

장면마다 하나씩 만들어요. 아래는 첫 장면(감방) 예시예요.

PROMPT · 잿빛 탑 원본
다크 판타지 포인트 앤 클릭 게임 배경, 1024x1024 정사각형, 사람 없음.
중세 석조 감방, 밤. 왼쪽 벽에 횃불, 가운데 쇠창살 창으로 들어오는 달빛 줄기,
왼쪽에 낡은 짚 침대, 오른쪽에 철 장식 아치형 나무 문, 벽 아래 틈으로 새는 촛불 빛,
바닥에 붉은 밀랍으로 봉한 쪽지.
포토리얼, 시네마틱 조명, 젖은 돌바닥 반사, 따뜻한 횃불과 차가운 달빛의 대비.

빈칸 템플릿 · 장면마다 { }만 바꿔서 쓰세요.

PROMPT · 빈칸 템플릿
{분위기. 예: 다크 판타지} 포인트 앤 클릭 게임 배경, 1024x1024 정사각형, 사람 없음.
{장소와 시간. 예: 중세 석조 감방, 밤}.
{화면 왼쪽에 있는 것}, {가운데에 있는 것}, {오른쪽에 있는 것},
{퍼즐에 쓰일 물건과 위치. 예: 바닥에 붉은 밀랍으로 봉한 쪽지}.
포토리얼, 시네마틱 조명, {조명 대비. 예: 따뜻한 횃불과 차가운 달빛의 대비}.
  • 톤 맞추기 · 다음 장면을 만들 때 이전 이미지를 레퍼런스로 넣고 "같은 조명과 색감 유지"를 붙이면 여러 장의 톤이 맞아요.
  • 상태 변화 이미지 · 침대 다리가 빠진 장면처럼 일부만 바뀐 이미지는 원본을 넣고 "이 물건 하나만 바꾸고 카메라와 구도는 그대로"라고 요청해요.

다 만들었으면 AI에게 이렇게 요청해요.

PROMPT
이 이미지들로 장면 배경을 교체하고, 클릭 영역 좌표를 각 이미지에 실제로 그려진 사물 위치에 맞춰 다시 잡아줘.
STEP 3

실시간 조명 효과

AI 코딩 도구

정지 이미지가 살아 있는 공간처럼 느껴지게 만드는 단계예요.

PROMPT
게임 장면 이미지 위에 WebGL 셰이더로 실시간 조명 레이어를 얹어줘. 게임 로직과 클릭 영역은 건드리지 마.
- 마우스를 따라다니는 등불 조명. 이미지 밝기로 노멀을 계산해서 돌벽 요철과 젖은 바닥이 빛에 반응하게
- 장면별 광원 설정(횃불과 촛불의 위치, 색, 깜빡임), 창문 달빛 줄기와 그 안에 떠다니는 먼지
- 바닥 안개, 물방울 파문, 블룸, 톤매핑, 마우스에 따라 살짝 움직이는 시차 효과
- 상단에 효과 켜기/끄기 버튼, WebGL이 안 되는 기기에서는 원래 이미지로 자동 대체
STEP 4

배경을 살아있는 영상으로

이미지 → 영상 AI

설정: 시작 프레임 = 장면 이미지, 6초, 1:1, 소리 끔. 공통 문장 뒤에 장면별 움직임만 바꿔 붙이세요.

PROMPT · 영상 생성
Locked-off static camera on a tripod, absolutely no camera movement, no zoom, no pan.
Only subtle ambient motion, everything else stays perfectly still.
No people appear, no new objects, room layout unchanged.
Photorealistic, cinematic, seamless ambient loop.
The wall torch and candle flames flicker naturally, faint dust drifts through the moonlight beams,
thin mist drifts low over the wet stone floor.

영상이 나오면 AI에게 이렇게 요청해요.

PROMPT · 게임에 합치기
장면별 루프 영상(mp4)을 게임에 넣어줘.
영상은 해상도가 낮으니 배경을 통째로 바꾸지 말고, 선명한 원본 이미지는 그대로 둔 채
영상의 '움직임'만 뽑아서 합쳐줘(영상 평균 프레임과의 차이를 더하는 방식).
불꽃 부분만 영상을 그대로 쓰고, 6초 이음매가 안 보이게 영상 두 개를 엇갈려 재생하며 겹쳐줘.
지금 보이는 방의 영상만 재생해.
STEP 5

링크로 공개하기

무료 호스팅
  1. 완성된 index.html 파일 하나를 준비해요.
  2. HTML 파일을 무료로 올릴 수 있는 정적 호스팅 서비스에 파일을 올리면 바로 링크가 생겨요. 유료 플랜은 필요 없어요.
  3. 링크를 공유하면 누구나 설치 없이 브라우저에서 바로 플레이할 수 있어요.
ADVANCED

한 번에 끝내기고급

이미지·영상 생성이 연결된 AI 코딩 에이전트

AI 코딩 에이전트에 이미지·영상 생성 기능을 연결해 쓰고 있다면, 1~4단계를 프롬프트 하나로 맡길 수 있어요. 이런 환경이 없다면 위의 1~5단계를 따라 하면 충분해요.

{ } 안을 내 기획으로 채워서 붙여 넣으세요.

PROMPT · 올인원
너는 게임 제작 디렉터야. 아래 기획으로 브라우저에서 바로 플레이할 수 있는 포인트 앤 클릭 미스터리 게임을 처음부터 끝까지 만들어줘. 단계마다 결과를 직접 확인하고 다음 단계로 넘어가.

[기획]
- 장르와 분위기: {예: 다크 판타지, 검은방 스타일 탈출+추리}
- 세계관: {2~3줄}
- 주인공: {이름, 직업, 숨긴 죄}
- 장면: {장면 6개 이름과 한 줄 설명}
- 인물: {4명, 이름과 각자의 비밀}
- 사건과 결말: {중반 사건, 범인, 엔딩 4개(배드 2, 노멀 1, 트루 1)}

[1단계 · 게임 본체]
HTML 파일 하나, 외부 라이브러리 없음. 클릭 조사, 소지품 사용과 조합, 키워드 수첩, 자물쇠 퍼즐, 힌트, 자동 저장, 엔딩 기록.
장면은 1024x1024 SVG와 클릭 영역, 장면별 이미지와 좌표는 한곳에서 관리.

[2단계 · 장면 이미지 (연결된 이미지 생성 도구)]
장면마다 1024x1024 실사풍 이미지, 사람 없음, 시네마틱 조명.
첫 장면을 다음 장면의 레퍼런스로 넣어 톤을 통일하고, 상태가 바뀌는 장면은 원본을 레퍼런스로 넣어 그 물건만 바꿔.
인물 초상화도 같은 톤으로. 생성된 이미지를 직접 보고 클릭 영역 좌표를 실제 사물 위치에 맞춰.

[3단계 · 살아있는 배경 (연결된 영상 생성 도구)]
장면 이미지를 시작 프레임으로 6초, 1:1, 무음 영상 생성.
프롬프트: "Locked-off static camera, absolutely no camera movement. Only subtle ambient motion, everything else stays perfectly still. No people, no new objects, room layout unchanged." 뒤에 장면별 불꽃, 먼지, 안개 움직임.
비용이 드는 설정이면 생성 전에 먼저 알려줘.

[4단계 · 조명과 합성]
WebGL로 마우스 등불 조명, 장면별 광원 깜빡임, 달빛, 안개, 블룸.
영상은 원본 이미지 위에 움직임만 합성(평균 프레임과의 차이), 불꽃 부분만 영상 그대로, 두 개를 엇갈려 재생해 이음매 숨기기. 효과 켜기/끄기 버튼.

[5단계 · 점검]
처음부터 모든 엔딩까지 직접 플레이해서 막히는 곳, 콘솔 오류, 모바일 화면을 확인하고 고친 뒤 결과를 보고해줘.
배포나 결제는 하지 말고 파일 완성까지만.
  • 한 번에 완벽하진 않아요 · 결과를 플레이해 보고 "이 장면 클릭 위치가 안 맞아", "불꽃이 너무 밝아"처럼 이어서 요청하면 금방 좋아져요.
  • 처음이라면 · 위의 1~5단계를 하나씩 따라 하는 쪽이 어디서 막혔는지 알기 쉬워요.
